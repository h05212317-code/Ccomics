# Ccomics

Android용 ZIP·CBZ 만화 서재입니다. 기기 폴더와 Windows SMB 공유를 연결하고, 폴더블 화면 폭에 따라 한 쪽 또는 양면으로 읽을 수 있습니다.

## 휴대폰에서 설치와 업데이트

1. [최신 릴리스](https://github.com/h05212317-code/Ccomics/releases/latest)의 **Ccomics.apk**를 휴대폰에서 열어 설치합니다. 1.0.3 이하에서는 이 과정이 한 번 필요합니다. 같은 서명의 기존 앱 위에 설치하면 책장과 읽던 위치가 유지됩니다.
2. 1.0.4부터 앱을 새로 실행하면 마지막 확인 후 6시간이 지났을 때 최신 정식 릴리스를 확인합니다. 바로 확인하려면 **서재 설정 → 앱 업데이트 확인**을 누릅니다.
3. 새 버전 안내에서 **다운로드 및 설치**를 누릅니다. 첫 업데이트에서 Android가 요청하면 **이 출처의 앱 허용**을 켠 뒤 돌아와 시스템 설치 화면에서 **업데이트**를 누릅니다. 휴대폰에서 GitHub 계정에 로그인할 필요는 없습니다.

## 새 버전 배포

이 프로젝트에서 Codex에 “수정한 내용을 새 버전으로 배포해 줘”라고 요청할 수 있습니다. 직접 배포할 때는 다음 순서를 사용합니다.

1. Windows에서 JDK 17, Android SDK Platform 35 및 Build Tools 35.0.0을 준비하고 JAVA_HOME과 ANDROID_HOME을 지정합니다. 현재 개발 PC에서는 build-apk.ps1이 기존 도구 경로를 찾습니다.
2. GitHub CLI에서 gh auth login과 gh auth setup-git을 실행합니다. 저장소에는 쓰기 권한이 필요합니다.
3. app/build.gradle에서 versionCode를 올리고 versionName을 더 높은 세 자리 버전으로 변경합니다. 예를 들어 5 / 1.0.4 다음은 6 / 1.0.5입니다. 변경한 소스와 버전을 커밋합니다.
4. PowerShell에서 아래 명령을 실행합니다.

```powershell
./publish.ps1 -Notes "이번 버전에서 바뀐 내용"
```

스크립트가 테스트와 서명 빌드를 실행하고 main에 소스를 푸시합니다. 해당 커밋의 초안 릴리스에 APK를 올려 SHA-256을 대조한 뒤 최신 릴리스로 공개합니다. 앱은 업데이트 APK의 해시, 패키지 이름, 설치된 앱과의 서명 일치 여부 및 버전 코드를 검사합니다.

공식 업데이트에는 기존 배포키가 필요합니다. 이 PC의 키와 Windows 사용자 계정으로 보호된 암호 파일은 %LOCALAPPDATA%\CcomicsSigning에 보관됩니다. 다른 PC에서 새 키로 서명하면 기존 설치본을 업데이트할 수 없습니다.

서재나 작품의 권 목록 맨 위에서 아래로 당겼다가 놓으면 등록된 기기 폴더와 SMB 공유를 다시 읽습니다. 확인된 삭제 파일은 책장에서 사라지고 같은 경로에 돌아오면 읽던 위치와 함께 다시 표시됩니다. 저장소 연결에 실패하면 기존 목록을 유지합니다. 권 번호 뒤에 원본·번역·해상도 표기가 붙은 파일도 새로고침할 때 시리즈로 묶고 권 번호순으로 정렬합니다. 제목 앞뒤에 붙은 괄호 문구([..] (..) {..} 【..】, 내용 무관)와 띄어쓰기·밑줄·문장부호 차이는 무시하고 같은 작품으로 묶습니다. `1~74권`, `1-74`, `전74권` 같은 범위 표기도 떼고 작품명만 씁니다. 권 번호가 없는 `블리치 (문구).zip`도 `블리치` 시리즈에 들어갑니다. 단, `외전.zip`·`표지.zip`처럼 흔한 이름은 같은 폴더 안에서만 묶습니다. 예를 들어 `[완결] 그 비스크 돌은 사랑을 한다 1권`과 `그_비스크_돌은_사랑을_한다_2권`은 한 시리즈입니다. 하위 폴더 안의 파일도 모두 읽습니다.

이미지 대신 권 ZIP을 담은 묶음 파일(예: `블리치 1~74권.zip` 안의 `블리치 1권.zip` … `블리치 70권.zip`)은 표지 이미지가 함께 있어도 안쪽 ZIP을 각각 한 권으로 등록하고 묶음 파일 자체는 책장에 표시하지 않습니다. ZIP 하나 안에 이미지가 `블리치 1권/`, `블리치 2권/`처럼 권별 폴더로 나뉘어 있어도 폴더마다 한 권으로 등록합니다(`1화/` 같은 화 폴더는 나누지 않음). `1권.zip`처럼 권 번호만 있는 안쪽 파일은 바깥 파일 이름을 작품명으로 씁니다. 무압축으로 담긴 권은 풀지 않고 바로 읽고, 압축된 권은 512MB 한도 안에서 임시 파일로 풀어 엽니다.

**서재 설정 → 책 이름만 표시**(기본 켜짐)는 제목 앞뒤·중간의 괄호·노이즈 표기(외전·번외 같은 구별 문구는 남김)와 권 번호 뒤의 원본·번역·해상도 표기를 숨기고, 작품 내부 책장에서는 `나루토 1권`, `나루토 10권`, `나루토 100권` 형태로 권 제목을 통일합니다. ZIP/CBZ 내부에 `ComicInfo.xml`이 있으면 작품명과 권 번호 인식에 함께 반영하고, 무의미 폴더(`스캔본`, `고화질`, `Download` 등)는 건너뛰고 상위 작품 폴더명을 인식합니다.

**서재 설정 → 표지 크기**에서는 슬라이더 바로 썸네일 크기를 조절하며 재실행 없이 즉시 책장에 반영됩니다. **별점순 표시하기**(기본 켜짐, 작품 길게 누르기에서 별점 지정)는 정렬과 별도로 ON/OFF할 수 있으며, 정렬은 제목순·최근 읽은순·최근 추가순·**사용자 정의**와 정방향(`↑`)·역방향(`↓`)을 지원합니다. 사용자 정의 정렬을 선택하면 상단에 **배치 모드** 아이콘이 나타나며, 작품을 꾹 눌러 드래그해 원하는 순서로 배치할 수 있습니다(별점순 표시하기가 켜져 있으면 같은 별점 구간 내에서만 이동).

## PC 원격 폴더 (외부에서 PC 만화 읽기)

PC가 켜져 있으면 휴대폰에 Tailscale을 켜지 않아도 밖에서 PC 폴더의 ZIP을 읽습니다. PC에서 `pc-server/ccomics-server.ps1`이 rclone(`serve webdav`, 읽기 전용, 127.0.0.1:17820)으로 폴더를 열고, Tailscale Funnel의 443 포트 `/ccomics` 경로가 그 서버로 연결합니다(CGV·롯데·메가 Catch의 기존 경로는 그대로).

- PC에 로그인하면 작업 스케줄러의 **Ccomics PC 서버** 작업이 서버를 숨김 창으로 띄우고, 서버가 꺼지면 10초 뒤 다시 띄웁니다.
- 폴더 목록·계정·비밀번호: `pc-server\data\config.json`(git 제외)의 `folders`에 여러 폴더를 넣을 수 있습니다. 바꾼 뒤 서버를 다시 실행합니다. rclone의 구글 드라이브 등 기존 설정 파일은 쓰지 않습니다.
- 앱: **책 추가 → PC 원격 폴더 연결**에 연결 코드(`https://계정:비밀번호@주소/ccomics/`)를 붙여 넣습니다.
- 원격 책은 처음 열 때 권 전체를 PC에서 8개 연결로 나눠 받아 휴대폰 보관함에 저장한 뒤 엽니다(실측: 111MB 약 49초, Funnel 중계 속도 약 2.3MB/s가 한계). 받다가 끊기면 받은 조각은 남겨 두고 다시 열 때 이어서 받습니다. 받은 권은 PC가 꺼져 있거나 인터넷이 없어도 바로 열리고, **서재 설정 → PC 원격 보관함 관리**에서 지우기 전까지 계속 남습니다.
- **서재 설정 → PC 원격 폴더**(기본 켜짐)를 끄면 원격 책을 책장에서 숨기고 새로고침 때 PC에 연결하지 않습니다.
- 외부에서 추가된 권은 작품 상세 책장에서 페이지 표시 오른쪽에 구름 아이콘이 붙습니다. PC가 꺼져 있으면 책장 목록은 마지막 상태로 남고, 열 때 연결 안내가 나옵니다.

## 독서 설정

작품을 열면 권별 표지가 서재와 같은 크기의 그리드로 표시됩니다. 읽기 방향은 전체 기본값으로 저장되며 **이 작품에만 적용 · 모든 권**을 선택하면 현재 시리즈에만 적용됩니다. 해제하고 저장하면 전체 기본 방향을 다시 따릅니다. **이 시리즈 첫 장 단독 표시**의 기본값은 꺼짐입니다.

기본 페이지 넘김은 드래그하면 종이 넘김, 좌우를 탭하면 즉시 전환입니다. **읽기 설정 → 넘김 효과**에서 두 동작에 각각 종이 넘김, 슬라이드, 즉시 전환을 지정할 수 있습니다.
