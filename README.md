# Ccomics

Android용 ZIP·CBZ 만화 서재입니다. 기기 폴더와 Windows SMB 공유를 연결하고, 폴더블 화면 폭에 따라 한 쪽 또는 양면으로 읽을 수 있습니다.

## 휴대폰에서 설치와 업데이트

1. [최신 릴리스](https://github.com/h05212317-code/Ccomics/releases/latest)의 **Ccomics.apk**를 휴대폰에서 열어 설치합니다. 1.0.3 이하에서는 이 과정이 한 번 필요합니다. 같은 서명의 기존 앱 위에 설치하면 책장과 읽던 위치가 유지됩니다.
2. 1.0.4부터 앱을 새로 실행하면 마지막 확인 후 6시간이 지났을 때 최신 정식 릴리스를 확인합니다. 바로 확인하려면 **서재 설정 → 앱 업데이트 확인**을 누릅니다.
3. 새 버전 안내에서 **다운로드 및 설치**를 누릅니다. 첫 업데이트에서 Android가 요청하면 **이 출처의 앱 허용**을 켠 뒤 돌아와 시스템 설치 화면에서 **업데이트**를 누릅니다. 휴대폰에서 GitHub 계정에 로그인할 필요는 없습니다.

## 새 버전 배포

이 프로젝트에서 Codex에 “수정한 내용을 새 버전으로 배포해 줘”라고 요청할 수 있습니다. 직접 배포할 때는 다음 순서를 사용합니다.

1. Windows에서 JDK 17, Android SDK Platform 35 및 Build Tools 35.0.0을 준비하고 JAVA_HOME과 ANDROID_HOME을 지정합니다. 현재 개발 PC에서는 build-apk.ps1이 기존 도구 경로를 찾습니다.
2. GitHub CLI에서 gh auth login과 gh auth setup-git을 실행합니다. 저장소에는 쓰기 권한이 필요합니다.
3. app/build.gradle에서 versionCode를 올리고 versionName을 더 높은 세 자리 버전으로 변경합니다. 예를 들어 5 / 1.0.4 다음은 6 / 1.0.5입니다. 변경한 소스와 버전을 커밋합니다.
4. PowerShell에서 아래 명령을 실행합니다.

```powershell
./publish.ps1 -Notes "이번 버전에서 바뀐 내용"
```

스크립트가 테스트와 서명 빌드를 실행하고 main에 소스를 푸시합니다. 해당 커밋의 초안 릴리스에 APK를 올려 SHA-256을 대조한 뒤 최신 릴리스로 공개합니다. 앱은 업데이트 APK의 해시, 패키지 이름, 설치된 앱과의 서명 일치 여부 및 버전 코드를 검사합니다.

공식 업데이트에는 기존 배포키가 필요합니다. 이 PC의 키와 Windows 사용자 계정으로 보호된 암호 파일은 %LOCALAPPDATA%\CcomicsSigning에 보관됩니다. 다른 PC에서 새 키로 서명하면 기존 설치본을 업데이트할 수 없습니다.

서재나 작품의 권 목록 맨 위에서 아래로 당겼다가 놓으면 등록된 기기 폴더와 SMB 공유를 다시 읽습니다.

## 독서 설정

작품을 열면 권별 표지가 서재와 같은 크기의 그리드로 표시됩니다. 읽기 방향은 전체 기본값으로 저장되며 **이 작품에만 적용 · 모든 권**을 선택하면 현재 시리즈에만 적용됩니다. 해제하고 저장하면 전체 기본 방향을 다시 따릅니다. **이 시리즈 첫 장 단독 표시**의 기본값은 꺼짐입니다.
